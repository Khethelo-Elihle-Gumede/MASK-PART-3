# MASK-PART-3
This is my Christoffel Chefs Menu Manager application that I have built for the manager as a junior developer.
In this application I was using JavaScript and React Native to develop this whole application.
This application was designed to help the manager of Christoffel to manage any shop items through a mobile device.
When I was building this application I made sure that it has a user-friendly interface that will allow the manager/chef to be
able to do anything needed by the shop,
Those things cloud be setting menus, updating, searching and deleting which has to be done by the chef/manager. 

In this POE I was instructed to develop mobile app for the restaurant and all the knowledge I have gained in class in using
React Native programming in this whole POE.

The Technologies used on this app are.
React Native
Javascript
Visual Studio Code to built this whole POE.

The features on this application Menu Management, Menu Information, User Experience, Menu Statistics, Search and Filtering.

What to find in all the features....

In the Menu Management:
-Update the menu 
-View all selling items
-Delete items in the menu

In the Menu Information:
-Dish Price
-Dish Names
-Course

In The User Experience:
-User Friendly Interface
-Same Layout
-Same Navigation

In the Menu Statistics:
-Total number of different courses
-The average prices of dishes

In the Search and Filtering:
-Search dish names 
-Filter dishes

My conclusion of the Christoffel Chefs Manager I show all my knowledge I gained in class on React Native. This knowledge helped me build this mobile application for the manager to keep in tabs with what's happening in the restaurant.
